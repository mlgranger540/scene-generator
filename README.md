# Matt Granger's Scene Generator!

This is a simple random scene idea generator I've created for writers like myself in need of story ideas ;)

## How It Works

The scene generator is a Jupyter Notebook file written in Python.

To run the notebook file online, you will need to use MyBinder by following [this link](https://mybinder.org/v2/gh/mlgranger540/scene-generator/HEAD?urlpath=%2Fdoc%2Ftree%2Fscene_generator.ipynb). This will then create an interactive environment where you can view and run the code!

It will take a moment for MyBinder to build the notebook. Once it loads, you can ignore what's there (it will come with whatever prompts had been generated when I last saved it to GitHub). Just press the play button in the top bar to run the code.

It will then ask you provide the names of the characters you want to use in your scene ideas. Simply type these in one at a time and press enter after each one. The minimum number of names required is **3** (**important: it will not work if you provide less than 3 as some of the prompts require 3 different names!**) and the maximum is **6**.

The code works by randomising the names provided by the user with different words/phrases contained in the CSV file. These include actions a character or characters might take, physical or emotional states characters could be in, reasons why something happened, topics that characters could talk or argue about, locations where things might be/take place, and items characters might come across and how they might use them. I will continue to add more to these as I think of them!

The resulting output is a series of statements using the inputted character names to create random ideas for scenes involving those characters!

### Output

There are currently **24** types of prompts that are generated by the code, which I've grouped into **5** categories:

#### Single Character Prompts

1. **Character + action** e.g. *A makes a promise*
2. **Character + *is* + descriptor** e.g. *A is angry*
3. **Character + *is* + descriptor + location** e.g. *A is crying in the bathroom*
4. **Character + *is* + location + *with nothing but* + item** e.g. *A is in a storm with nothing but a scarf*

#### Multiple Character Prompts

5. **Character + action + character** e.g. *A betrays B*
6. **Character + *is* + descriptor + *with* + character** e.g. *A is going crazy with B*
7. **Character + *is* + location + *with* + character** e.g. *A is at the cinema with B*
8. **Character + *is* + descriptor + *with* + character + location** e.g. *A is having fun with B in a haunted house*

#### Multiple Character Prompts with Reasons

9. **Character + action + character + *because* + reason** e.g. *A shouts at B because they made a terrible mistake*
10. **Character + action + character + *after* + reason** e.g. *A saves B after something went horribly wrong*
11. **Character + action + character + *because* + character + reason** e.g. *A kisses B because C broke their heart*
12. **Character + action + character + *after* + character + reason** e.g. *A laughs at B after B did something stupid*

#### Conversation/Argument Prompts

13. **Character + *has a conversation with* + character + *about* + topic** e.g. *A has a conversation with B about a crazy dream they had*
14. **Character + *has a conversation with* + character + *and* + character + *about* + topic** e.g. *A has a conversation with B and C about their favourite movies*
15. **Character + *has a conversation with* + character + *about* + topic + location** e.g. *A has a conversation with B about past relationships on a spaceship*
16. **Character + *has an argument with* + character + *about* + topic** e.g. *A has an argument with B about a breakup*
17. **Character + *has an argument with* + character + *and* + character + *about* + topic** e.g. *A has an argument with B and C about a theft*
18. **Character + *has an argument with* + character + *about* + topic + location** e.g. *A has an argument with B about a personal problem at a bar*

#### Item Prompts
19. **Character + *finds* + item + *somewhere unexpected*** e.g. *A finds a cat somewhere unexpected*
20. **Character + *finds* + item + location** e.g. *A finds a sword in the sea*
21. **Character + *gives* + character + item** e.g. *A gives B a map*
22. **Character + *steals* + item + *from* + character** e.g. *A steals a hat from B*
23. **Character + *uses* + item + *to* + use** e.g. *A uses a knife to open a locked door*
24. **Character + *uses* + item + *and* + item + *to* + use** e.g. *A uses a banana and a chicken to do something random*
