# Matt Granger's Scene Generator!

This is a simple random scene idea generator I've created for writers like myself in need of story ideas ;)

## How It Works

The scene generator is a Jupyter Notebook file written in Python. When the code is run using `Run All`, it will ask for text input - these are the character names you want to use in the scene ideas. The minimum number of names required is **3** and the maximum is **6**.

To render the file from GitHub, you will need to use [mybinder](https://mybinder.org/) and enter the location of the file on GitHub: **mlgranger/scene-generator**.

The code works by randomising the names provided by the user with different words/phrases contained in the CSV file. These include actions a character or characters might take, reasons why something happened, items characters might use and how they might use them, and conversation topics characters could have with each other. I will continue to add more to these as I think of them!

The resulting output is a series of statements using the user's character names to create random ideas for scenes involving those characters!

### Output

There are currently **6** types of scene ideas that are generated by the code:

1. **Character + action** e.g. *A makes a promise*
2. **Character + action + character** e.g. *A betrays B*
3. **Character + action + character + connective + reason** e.g. *A is saved by B after something went horribly wrong*
4. **Character + action + character + connective + character + reason** e.g. *A kisses B because C broke their heart*
5. **Character + *has a conversation with* + character(s) + *about* + topic** e.g. *A has a conversation with B about a crazy dream they had*
6. **Character + *uses* + item(s) + *to* + use** e.g. *A uses a knife to open a locked door*
